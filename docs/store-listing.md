## Description courte (80 car. Play)

Gestion école coranique : appel, notes, messages et annonces pour mosquée.

## Description longue (extrait)

MadrasApp centralise la vie de l'école coranique de votre mosquée : emploi du temps, appels de présence, notes, devoirs, annonces et messagerie sécurisée entre administration, enseignants, parents et élèves. Chaque mosquée dispose de son espace isolé. Notifications optionnelles pour les annonces, messages et absences (sans données sensibles dans les alertes).
